# Zelda Clone in Pure JavaScript

A small **Zelda-inspired top-down action RPG prototype** built with **pure JavaScript**, **HTML5 Canvas**, and **pixel art sprites**.

> **Note:** This project is still in a very early stage and is part of my learning journey in **game development**. I’m still new to building games, so this repository is both a game prototype and a study project. The game will continue to improve over time as I learn more about programming, animation, combat systems, sprite workflows, and game structure.

---

## About the Project

This project is inspired by classic **top-down action-adventure games**, especially older Zelda-style games.  
The goal is to recreate the foundation of that experience using **vanilla JavaScript**, without relying on external game engines.

At the same time, this repository is also a place for me to **learn by building**. As I continue studying game development, I plan to keep improving the codebase, polishing the gameplay, refining the sprite system, and gradually adding new mechanics and content.

Because of that, some systems are still incomplete, experimental, or likely to change over time.

---

## Current Goals

The current focus of the project is building the core foundation of the game, including:

- 4-direction player movement
- top-down sprite animation
- sprite sheet rendering
- basic sword attack mechanics
- shield / defense system
- collision and movement logic
- general game structure in pure JavaScript
