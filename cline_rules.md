# Projeto

Este é um jogo top-down 2D em Vanilla JavaScript usando Canvas API.

## Regras

- Sempre priorize código modular.
- Siga SOLID quando fizer sentido.
- Não quebre compatibilidade sem justificar.
- Antes de implementar features complexas, proponha a arquitetura.
